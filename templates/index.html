💡 How collections.deque Works for Palindromes

Why not standard Python lists?

In a standard Python list, pop(0) (removing the first element) takes O(n) time because all subsequent elements must be shifted in memory.

A collections.deque (Double-Ended Queue) is implemented as a doubly linked list of blocks in C. Both popleft() and pop() execute in O(1) constant time.

Algorithm Workflow

  1. Preprocess: Normalize text (case, whitespace, punctuation).
  2. Load: Enqueue all filtered characters into deque(chars).
  3. Compare: While len(deque) > 1, simultaneously pop front = popleft() and rear = pop().
  4. Verify: If front != rear, terminate early with False. If the loop completes, return True.
Python collections.deque Core Logic Python 3 
from collections import deque

def is_palindrome_deque(cleaned_text: str) -> bool:
    char_deque = deque(cleaned_text)
    while len(char_deque) > 1:
        front = char_deque.popleft()  # O(1) from head
        rear = char_deque.pop()       # O(1) from tail
        if front != rear:
            return False
    return True
